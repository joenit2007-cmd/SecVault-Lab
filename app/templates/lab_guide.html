Local Vulnerability Assessment & Remediation Lab Guide

Use these safe, local-only test cases against http://127.0.0.1:5000 first in Vulnerable Mode (python run.py --mode vulnerable) and then repeat them in Secure Mode (python run.py --mode secure) to verify every remediation.

1. SQL Injection (OWASP A03)

Login Bypass: On /login, enter username:

' OR '1'='1' --

Search Data Leakage: On /dashboard search box, submit:

' OR '1'='1' --

Secure Result: Parameterized queries treat input as literal text; login fails and only your own notes remain visible.

2. Cross-Site Scripting — XSS (OWASP A03)

Reflected XSS: Search on /dashboard with:

<script>alert('XSS_Reflected_Demo')</script>

Stored XSS: Create a note containing an HTML/JS payload.

Secure Result: Jinja2 autoescaping renders tags harmlessly as text, and CSP blocks inline scripts.

3. Broken Access Control (OWASP A01)

IDOR: Sign in as a second user and visit another user's note URL such as /notes/1.

Vertical Privilege Escalation: As a normal user, navigate directly to /admin.

Secure Result: Server-side ownership and RBAC checks return 403 Forbidden and record an audit event.

4. Authentication Failures (OWASP A07)

Weak Passwords & Plaintext: Register with password 123 in vulnerable mode.

Brute Force & Enumeration: Submit 6 wrong passwords on /login.

Secure Result: Enforces strong password rules, salted PBKDF2-SHA256 hashing, generic login errors, and HTTP 429 lockout after 5 failures.

5. Security Misconfiguration (OWASP A05)

Exposed Diagnostics: Visit /debug/info and /debug/error-test.

HTTP Headers: Inspect response headers in DevTools (CSP, X-Frame-Options, X-Content-Type-Options, HttpOnly cookie).

Secure Result: Debug endpoints return 404, headers are hardened, and cookies enforce HttpOnly & SameSite=Lax.

6. Cross-Site Request Forgery — CSRF (CWE-352)

Forged State Change: While signed in, open the Local CSRF Simulator and trigger the forged POST without a CSRF token.

Secure Result: Missing/invalid CSRF token is rejected with 403 Forbidden and logged as CSRF_BLOCKED.
